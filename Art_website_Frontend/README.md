# Muse Tales Art frontend

This is the React and Vite frontend for Muse Tales Art. For the complete project overview and instructions for running both the frontend and backend, see the repository [README](../README.md).

## Run locally

```bash
npm install
```

Copy `.env.example` to `.env` and set `VITE_MAPBOX_TOKEN` to a Mapbox access token, then start the development server:

```bash
npm run dev
```

The frontend expects the API at `http://localhost:5000`. Other available commands are `npm run build`, `npm run preview`, and `npm run lint`.
